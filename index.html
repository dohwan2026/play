기준 회차

번호 생성

게임 수를 고르고 ‘번호 뽑기’를 누르세요.

알고리즘 고르기

기준 회차 직전 몇 번 동안, 각 알고리즘을 적용해 뽑은 번호가 실제 다음 회차와 얼마나 맞았는지 비교합니다. 1등 알고리즘으로 번호를 뽑습니다.

비교할 횟수
1등 알고리즘의 회차별 성적

번호별 점수

과거 검증

200회부터 매 회차마다 “직전 몇 번 성적 1등 알고리즘”의 상위 6개를 뽑았다면, 실제 다음 회차와 평균 몇 개가 맞았을까?

계산 방식

후보 알고리즘은 13개이고, 모두 기준 회차를 포함한 최근 최대 3개 회차를 입력으로 씁니다. 닮은 흐름(최근 1~3회와 닮았던 과거 구간의 다음 회차 번호), 재등장(최근 번호와 ±1 이웃), 쉬어간 번호(최근에 안 나온 번호), 번호 이동(역대 “이 번호 다음엔 저 번호” 횟수), 전체 빈도(비교용)입니다.

예를 들어 비교할 횟수가 2면, 기준이 4회일 때 각 알고리즘을 2회까지의 데이터로 돌려 3회를 맞혀 보고, 3회까지의 데이터로 돌려 4회를 맞혀 봅니다. 두 번의 평균 성적이 가장 좋은 알고리즘을 4회까지의 데이터에 적용해 5회 번호를 냅니다. 성적은 실제 당첨번호 6개에 그 알고리즘이 준 확률을 합한 값(기대 일치 개수)이고, 무작위는 0.8개입니다. 게임은 1등 알고리즘의 번호별 확률에 비례해 뽑고, 여러 게임이면 앞 게임과 번호가 덜 겹치도록 조정합니다.

재미용입니다. 로또 추첨은 매번 독립적이라 어떤 방식도 실제 당첨 확률을 바꾸지 못합니다.
